Что означают показатели

Плотность оплётки — расчётная доля поверхности заготовки, покрытая проволочной оплёткой.P = (2 × Пл − Пл²) × 100

Угол — угол проволок к плоскости, перпендикулярной оси кабеля, согласно формуле:α = atan(s / (π × (D + 2 × d)))
Угол в градусах = α × 180 / π

Пл — безразмерный коэффициент заполнения оплётки в одном направлении. Используется для расчёта общей плотности покрытия.Пл = (N × n × d) / (2 × s × cos(α))

Размеры — в миллиметрах. В тригонометрических функциях угол α используется в радианах.

Правила выбора Кпп
  • От 0 % до 70 %, не включая 70 %
    Допущение для оценки    ≈ 1,030
  • 70–80 % включительно1,030
  • Выше 80 % и ниже 96 %
    Линейная интерполяция    1,030–1,035
  • 96–100 % включительно1,035

В промежутке 80–96 %: Кпп = 1,030 + (P − 80) × 0,005 / 16Здесь P — плотность оплётки в процентах. Например, при 88 % Кпп = 1,0325.

Таблица 25 СТБ 2194-2011 задаёт значения для 70–80 % и 96–100 % и предусматривает интерполяцию между ними. Ниже 70 % в калькуляторе условно принят Кпп = 1,030: это допущение, не значение из стандарта; расход обозначен знаком ≈.

Кпп — безразмерный показатель, учитывающий увеличение массы из-за пересечения прядей. Одинаковый для обоих материалов. Расчёт использует неокруглённые плотность и Кпп.

СТБ 2194-2011, таблица 25, страница 28 (PDF)

Как рассчитывается расход

M = [N × n × π × (d × 0,001)² × ρ × Кпп × 1000] / [4 × sin(α)]

ρ — плотность материала: для меди 8890 кг/м³, для стали 7800 кг/м³. Коэффициент 0,001 переводит диаметр проволоки в метры, 1000 — расход в кг/км.
