# Расчёт оплётки

Статический калькулятор для GitHub Pages. Не требует установки, сборки или сервера: стили, JavaScript и значок встроены в index.html. Работает и при открытии файла на компьютере. Интерфейс адаптирован для смартфона.

## Публикация

1. Создайте репозиторий GitHub.
2. Распакуйте архив и загрузите его содержимое в корень репозитория: index.html, README.md и .nojekyll. Не загружайте сам ZIP вместо файлов.
3. В Settings → Pages выберите Deploy from a branch.
4. Выберите ветку main, папку / (root) и нажмите Save.
5. После публикации откройте адрес, показанный в разделе Pages.

Если файлы загружены в другую ветку, выберите её вместо main. Главная страница должна называться index.html и находиться в выбранной папке.

## Расчёты

Формулы, исходные значения и правила Кпп сохранены из предоставленного файла. Правило Кпп задано только для плотности 70–80 % и 96–100 %; при остальных значениях расход не рассчитывается. Адаптация для GitHub не меняет расчётную методику.

## Обновление

Замените index.html в репозитории новой версией. GitHub Pages повторно опубликует страницу.
