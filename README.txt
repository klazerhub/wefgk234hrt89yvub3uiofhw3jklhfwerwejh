УСТАНОВКА ИКОНОК

1. Распакуйте архив.
2. Загрузите ВСЕ файлы рядом с index.html в корень вашего сайта или репозитория GitHub Pages. Замените прежний index.html.
3. Дождитесь публикации сайта и обновите вкладку браузера.
4. На iPhone откройте сайт в Safari → Поделиться → На экран «Домой».
Если ранее добавленный ярлык показывает старую иконку, удалите только этот ярлык и добавьте его снова.

apple-touch-icon.png — 180×180, PNG, для iPhone.
favicon.svg — векторная иконка для современных браузеров.
favicon.ico — размеры 16×16, 32×32 и 48×48.
favicon-16x16.png и favicon-32x32.png — дополнительные варианты вкладки.

Формулы и интерфейс калькулятора не изменены.
